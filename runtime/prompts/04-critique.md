# Phase 4: validate and critique

Keep three mechanisms separate.

## Class A validation

Test binary obligations such as accessibility blockers, legal claims, protected-file integrity, security, destructive changes, and required state coverage. A blocker or major Class A failure makes the candidate ineligible.

## Class B scoring

Measure task clarity, hierarchy, density, responsiveness, performance, content integrity, and maintainability. Use intent-defined quality floors.

## Class C critique

Judge intent alignment, coherence, distinctiveness, emotional register, analogy quality, and tradeoff quality. Use pairwise comparison rather than unsupported absolute taste scores when the distinction is subtle.

Every finding must contain:

- unique id
- class and dimension
- source
- status
- normalized score and confidence
- severity
- exact state reference
- semantic node reference
- observable evidence
- rationale linked to intent
- actionable recommendation

Do not use aesthetic certainty where reasonable experts could disagree. Record disagreement as uncertainty.
