# Phase 4: validate and critique

Evaluate the rendered, content-addressed artifact. Do not evaluate a manifest, prompt, or design rationale as a substitute for the implementation.

Capture every required state and workflow with screenshot and node-map hashes. Derive workflow status from the complete declared step and assertion set rather than accepting a self-reported pass. Extract rendered layout, palette, typography, and density profiles. Evidence tied to a different artifact reference is stale and invalid.

Keep three mechanisms separate.

## Class A validation

Test binary obligations such as accessibility blockers, functional workflow completion, legal and claim provenance, protected-file integrity, security, destructive changes, and required state coverage. A blocker or major Class A failure makes the candidate ineligible.

## Class B scoring

Measure task clarity, hierarchy, density, responsiveness, clipping, overlap, reading measure, performance, content integrity, and maintainability. Use intent-defined quality floors and exact browser states.

## Class C critique

Judge intent alignment, visual coherence, distinctiveness, emotional register, contextual fit, analogy quality, and tradeoff quality. Prefer pairwise comparison over unsupported absolute taste scores when the distinction is subtle. Treat reasonable expert disagreement as uncertainty.

For every intent principle and candidate commitment, link evidence with its canonical obligation reference and classify implementation as `full`, `partial`, `none`, or `unknown`. This produces the Thinking Fidelity Score and Principle Adherence Score. A rationale that is not visible in the artifact receives no credit.

Every finding must contain:

- unique id
- class and dimension
- source
- status
- normalized score and confidence
- severity
- exact state reference
- semantic node reference
- observable evidence
- rationale linked to intent
- actionable recommendation
- obligation references and implementation classification when the finding verifies a principle or commitment

The generator must not certify its own work. Use independently sourced evaluators for pairwise judgment, bind each comparison to both artifact references, state the intent-linked criteria, and preserve abstention and disagreement.
