# Phase 2: explore directions

Generate at least three coherent directions from the validated intent.

Each direction must differ materially across composition, typography, spatial rhythm, surface, imagery, interaction, voice, and product-flow structure. A palette, font, border-radius, prompt, or candidate name change does not create a new direction. Rendered layout, palette, typography, and density fingerprints will be compared after implementation.

For every direction provide:

- one sentence thesis
- user hypothesis
- structural pattern and page or flow sequence
- decision rationale and deliberate tradeoffs
- rejected category conventions
- evidence that would falsify the direction
- implementation risks
- an immutable content-addressed artifact reference
- an immutable baseline reference, allowed paths, protected paths, and diff-only change contract
- concrete candidate commitments that make the rationale testable in every required state

A commitment is not an aspiration. It states what will exist in the artifact, its obligation class and severity, the quality dimension it affects, every state in which it must hold, and how implementation will be verified. Use a bounded automated check only when the browser can measure the claim directly.

Do not merge directions during generation. Do not score while generating. Do not write alternate prose around the same layout. Retrieve references for functional analogy and principles, then create an original composition from product truth.
